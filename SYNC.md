# Sync playbook — Claude Design → this repo

This repo mirrors the **Reanimation Design System** in Claude Design. Claude Design is the source of truth; this repo is never edited by hand. When the user says **"Sync from the design system"** (or "sync Reanimation"), follow these steps exactly.

- Source: https://claude.ai/artifact/QCyLDQ9UgGoPDd8ikjU8EE (a Design System artifact owned by the user)
- `source/` = an exact copy of the artifact's `project/` folder, plus the asset files under `source/assets/<Group>/`
- `design-system/` = generated by `scripts/build_package.py` from `source/`. Never edit it.

## Path A — read the artifact directly (preferred)

1. **Check access.** Use the Artifact tool: `action: "list"`, `scope: "files"`, `url` = the source above. If the tool isn't available or the read fails, stop and go to **Path B**. Tell the user which happened.
2. **Is there anything new?** Read `project/design-system.json`. Compare its `lastChange` to `lastChange` in `source/design-system.json`. If they're identical, tell the user "Already up to date (last change: <at> — <note>)" and stop. If `source/` doesn't exist yet, this is the **first sync**: copy everything.
3. **Branch.** `git checkout -b sync/<YYYY-MM-DD-HHMM>` from an up-to-date `main` (skip on the first sync if `main` has no commits yet).
4. **Copy the files.** For every path in the listing that starts with `project/`, read it (`action: "read"`, `paths`, up to 256 per call, `out_dir` = a scratch folder) and write it to `source/<path without "project/">`. Copy bytes exactly; don't reformat. Skip everything outside `project/` (`SKILL.md`, `artifact-type/`, `index.html` belong to the artifact type, not the system).
5. **Remove deleted files.** Any file under `source/` that is not in the listing — except the asset files in `source/assets/<Group>/` other than `README.md` — was deleted in Claude Design. Delete it here too.
6. **Assets.** On the first sync, fetch every file in `assetGroups`. Otherwise compare `assetGroups` in the new `source/design-system.json` with the old one (`git diff`). For each added or changed file, fetch it with `action: "read"`, `path` = its `blob` id, and save it as `source/assets/<Group>/<file name>`. Delete asset files whose entries were removed. If nothing changed, skip this step.
7. **Build and check.**
   ```
   python3 scripts/build_package.py
   node scripts/check.mjs
   ```
   If either fails, stop, don't commit, and show the user the error.
8. **Version.** On the first sync keep `0.1.0`. Otherwise bump `version` in `package.json` (semver):
   - **patch**: docs, guidance, visual fixes, no API change
   - **minor**: new components, new props or new tokens
   - **major**: renamed or removed components, props or tokens (say so loudly in the PR)
9. **Changelog.** Add an entry at the top of `CHANGELOG.md`: version, date, the `lastChange.note` from Claude Design, then a short list of what changed — from `git diff --stat source/` (components added/changed/removed, token changes).
10. **Commit, push, open a PR.** (First sync: if `main` has no commits yet, commit straight to `main` with the message `Initial import from Claude Design` instead.) Commit message: `Sync from Claude Design: <lastChange.note, first sentence>`. Open a pull request to `main` with the changelog entry as its description. Don't merge it; the user reviews and merges.
11. **Report** to the user in two or three lines: the new version, what changed, and the PR link.

## Path B — update zip from Claude (fallback)

Use this when this session can't read the artifact. The user asks Claude (in the Claude app, where the design system lives) for a **"Reanimation update zip"** and attaches it here.

1. Unzip into a scratch folder. It contains a `source/` folder.
2. Branch as in A3.
3. Replace this repo's `source/` with the zip's `source/` (delete, then copy, so removed files go away).
4. Continue from **A7** (build, check, version, changelog, PR, report).

## Never

- Never edit `design-system/`, `source/` or the components by hand to "fix" something. If you find a bug, report it to the user; it gets fixed in Claude Design and synced.
- Never push straight to `main`.
- Never change the agent rules (`AGENTS.md`, `templates/`) during a sync unless the user asks.
