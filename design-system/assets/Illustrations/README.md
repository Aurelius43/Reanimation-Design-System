# Assets · Illustrations

Files live in `design-system/assets/Illustrations/`. Copy them as-is; never redraw or approximate.

## Use

```html
<img src="design-system/assets/Illustrations/cover-maestro-orchestra.png" alt="…">
```

## Usage notes

Authored raster artwork from the Bone Maestro illustration system. Use as-is; never filter, recolor or crop away eyes, skulls, hands, tools or the defining action.

- `cover-*`, `poster-*` — campaign and editorial key art (hero, launch, store, poster study). Poster type lives in the art; do not add more on top.
- `character-maestro`, `character-tech`, `character-roadie` — front-facing key art for the three-character cast. `character-maestro-cutout` and `character-slime-amp` — full-body cutouts on black.
- `scene-*` — wide editorial scenes and scene artwork (`scene-signal-bloom` is album-style scene art used in the iOS app).
- `spot-*` — single subject-action marks for empty states, setup steps and editorial callouts (on Bone paper). The Empty state pattern uses `spot-empty-stage`, `spot-no-results` and `spot-offline-cable`; `spot-skull-trophy` marks an achievement.
- `micro-*` — compact single-subject symbols on black for cues, metadata and secondary punctuation.

Place art on `background-canvas` or `surface`; keep text off busy areas and give every meaningful image alt text (decorative art gets empty alt).
