# Assets · Logos

Files live in `design-system/assets/Logos/`. Copy them as-is; never redraw or approximate.

## Use

```html
<img src="design-system/assets/Logos/app-icon-dark.svg" alt="…">
```

## Usage notes

Bone Maestro marks, exported as vectors from the design file.

- `app-icon-dark.svg` — primary app icon: the Conductor baton + bone X with toxic, magenta and cyan burst on Ink 950. Default for dark contexts and stores.
- `app-icon-light.svg` — the same artwork on a Bone ground for light contexts.
- `app-icon-tint-ready.svg` — monochrome grey version for system tinting (iOS tinted icons). Do not recolor by hand.
- `lockup-stacked.svg` — mark above "BONE MAESTRO" in Barlow Condensed Black. The wordmark ink is Bone 50 (`ra-core-color-bone-50`): place on Ink 950–850 grounds only.
- `lockup-horizontal-monogram.svg` — compact "BM" monogram disc with the "Bone Maestro" wordmark, from the illustration board. The disc is a bright chartreuse (#c8ff00) that is not a system token, and the wordmark ink is Bone 50: dark grounds only.

Keep clear space of at least half the mark's width; never redraw, outline, rotate or add effects to the mark.
