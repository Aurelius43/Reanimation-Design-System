## Guidance

Material 3 search: collapsed Bar (56dp, fully rounded, `surface-raised`) that opens a full-screen Expanded view with query field and results.

`mode` (`bar | expanded`), `placeholder`, `query`, children (results). Keyboard, focus, clearing, result announcements and system Back belong to the runtime.
