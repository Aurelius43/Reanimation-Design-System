# SpotIllustration

Geometric spot for empty states: No data (creative), No results (information), Offline (warning), Completed (success).

`RA.SpotIllustration` · 11e — Feedback + Overlays

## Use

```jsx
<RA.SpotIllustration />
```


## Props (SpotIllustrationProps)

| prop | type | note |
| --- | --- | --- |
| `variant` | `"no-data" \| "no-results" \| "offline" \| "completed"` |  |

## Guidance

Geometric spot for empty states: No data (creative), No results (information), Offline (warning), Completed (success).

`variant`. Backdrop `background-interactive`, orbit and icon tile in the tone, accents in `mutation-special` and `mutation-creative`. Decorative: hidden from assistive tech. For editorial empty states use the authored spot illustrations in `assets/Illustrations`.
