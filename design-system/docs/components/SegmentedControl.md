# SegmentedControl

Compatibility fixed-three segmented preset (Day / Week / Month) over ChoiceGroup segments.

`RA.SegmentedControl` · 11d — Navigation

## Use

```jsx
<RA.SegmentedControl />
```


## Props (SegmentedControlProps)

_Props are `Partial<ChoiceGroupProps>`, inherited from the library this wraps — not spelled out in `components/index.d.ts`; see the long README._

## Guidance

Compatibility fixed-three segmented preset (Day / Week / Month) over ChoiceGroup segments.

44px track on `background-subtle` (4px padding, 10px radius); the selected segment sits on `background-surface`. Pass `items` to rename; use ChoiceGroup for other counts and native pickers where available.
