# PrimaryNavigation

Canonical four-destination navigation (Connect, Control, Library, Scenes) placed for iPhone tabs, iPad sidebar, Web sidebar or Web top.

`RA.PrimaryNavigation` · 11d — Navigation

## Use

```jsx
<RA.PrimaryNavigation />
```


## Props (PrimaryNavigationProps)

| prop | type | note |
| --- | --- | --- |
| `placement` | `"iphone" \| "ipad" \| "web-sidebar" \| "web-top"` |  |
| `selected` | `"connect" \| "control" \| "library" \| "scenes"` |  |

## Guidance

Canonical four-destination navigation (Connect, Control, Library, Scenes) placed for iPhone tabs, iPad sidebar, Web sidebar or Web top.

`placement` (`iphone | ipad | web-sidebar | web-top`), `selected`. iPhone tabs reserve the 34pt home-indicator area. On Android use AndroidNavigation.
