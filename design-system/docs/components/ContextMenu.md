# ContextMenu

Compatibility preset of cue commands over MenuSurface (Cut, Copy, Paste after, Delete).

`RA.ContextMenu` · 11e — Feedback + Overlays

## Use

```jsx
<RA.ContextMenu />
```


## Props (ContextMenuProps)

_Props are `Partial<MenuSurfaceProps>`, inherited from the library this wraps — not spelled out in `components/index.d.ts`; see the long README._

## Guidance

Compatibility preset of cue commands over MenuSurface (Cut, Copy, Paste after, Delete). Use native context menus on iOS and Android.

Pass `items` to replace the commands.
