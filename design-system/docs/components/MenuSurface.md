# MenuSurface

Anchored or context command surface with a variable items list.

`RA.MenuSurface` · 11e — Feedback + Overlays

## Use

```jsx
<RA.MenuSurface />
```


## Props (MenuSurfaceProps)

_No props of its own._

## Guidance

Anchored or context command surface with a variable items list.

`items` (MenuItem props, `"-"` separators, `{ group }` headings), `label`, children. 8px padding, 4px gap, `radius-lg`, `overlay-surface`, `border-strong`, `elevation-2`. Implement full menu keyboard behavior (arrows, Home/End, typeahead, Escape) or use native menus.
