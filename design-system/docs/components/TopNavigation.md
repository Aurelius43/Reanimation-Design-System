## Props (TopNavigationProps)

_No props of its own._

## Guidance

Compatibility top bar: Desktop or Mobile × Normal, Live or Performance mode.

`brand`, `items` (`[{ label, href, active }]`), `mode`, `viewport` (`desktop | mobile`), `initials`. 64px, 24px side padding (16 mobile), `background-surface`, `border-subtle` bottom rule. Mode badges announce LIVE (`mutation-live`) or PERFORMANCE (`mutation-special`) with text, never color alone. Canonical app destinations are Connect / Control / Library / Scenes — use PrimaryNavigation for new work.
