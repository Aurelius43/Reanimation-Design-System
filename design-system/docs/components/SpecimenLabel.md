## Guidance

Production equipment markings for scene, device, signal, cue and live metadata — Micro, Inline, Card, Panel, Editorial.

`variant`, `index`, `k` (key), `value`, `format`, `classification`. Always `KEY // VALUE`: exactly two slashes with one space each side, no trailing punctuation, uppercase Geist Mono. Index and accent text in `action-primary` (toxic in Dark; olive in Light for 4.5:1). Specimen Labels classify compact operational metadata; they are not a global type style or a substitute for plain language.
