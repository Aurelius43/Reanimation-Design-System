# DropdownMenu

Compatibility preset of performance commands over MenuSurface (group label, Open, Rename, Duplicate, Live mode check, Delete).

`RA.DropdownMenu` · 11e — Feedback + Overlays

## Use

```jsx
<RA.DropdownMenu />
```


## Props (DropdownMenuProps)

_Props are `Partial<MenuSurfaceProps>`, inherited from the library this wraps — not spelled out in `components/index.d.ts`; see the long README._

## Guidance

Compatibility preset of performance commands over MenuSurface (group label, Open, Rename, Duplicate, Live mode check, Delete).

Pass `items` to replace the commands; for arbitrary menus compose MenuSurface directly.
