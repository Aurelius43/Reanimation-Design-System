## Guidance

How expressive a context may be: M0 Clean, M1 Signal, M2 Active, M3 Performance, M4 Campaign.

`level`, `label`. Code in Geist Mono; M0–M2 names in Geist, M3–M4 in Barlow Condensed ExtraBold uppercase. M4 Campaign sits on an `action-primary` plate (toxic in Dark) with `action-on-primary` copy with the hard graphic shadow. Mutation level is not operational state: M3 Live does not require M3 expression.
