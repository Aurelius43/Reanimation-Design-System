# AndroidAppBar

Material 3 small top app bar: Default (flat) or Scrolled (on-scroll surface).

`RA.AndroidAppBar` · 25 — Android Core

## Use

```jsx
<RA.AndroidAppBar />
```


## Props (AndroidAppBarProps)

| prop | type | note |
| --- | --- | --- |
| `title` | `string` |  |
| `scrolled` | `boolean` |  |

## Guidance

Material 3 small top app bar: Default (flat) or Scrolled (on-scroll surface).

`title`, `scrolled`. 64dp; navigation, search and overflow actions are 48dp targets with accessible names. The runtime owns scroll behavior, insets and system bar contrast.
