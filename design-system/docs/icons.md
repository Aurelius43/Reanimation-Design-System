# Icons

18 named glyphs from the icon font in `components/bundle.css`. Never draw an SVG icon the system has.

## Use

```jsx
<RA.Icon name="add" />
```


## Names

`add`, `arrow-right`, `close`, `connect-filled`, `connect-outline`, `control-filled`, `control-outline`, `expand`, `folder-lock`, `library-filled`, `library-outline`, `loading`, `pause`, `play`, `radio`, `scenes-filled`, `scenes-outline`, `stop`
