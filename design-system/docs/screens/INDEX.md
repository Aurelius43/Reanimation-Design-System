# Reference screens

Full iPhone and iPad layouts built from the components. Copy their composition when building a screen.

- [`ScreenDevices`](ScreenDevices.md) — Every stage device: what's in tonight's show, what's nearby, and what needs help.
- [`ScreenLibrary`](ScreenLibrary.md) — Everything that isn't on tonight's running order: scenes and saved shows.
- [`ScreenLive`](ScreenLive.md) — Running a show. The live controls never move, never scroll away and never get covered.
- [`ScreenSettings`](ScreenSettings.md) — App preferences, plus where people fix permissions.
- [`ScreenShowDetail`](ScreenShowDetail.md) — One show's set list: every scene in cue order, with the live, armed (Next) and problem scenes easy to spot.
- [`ScreenTonight`](ScreenTonight.md) — The home screen for a night: every show in running order, with the live show front and center.
