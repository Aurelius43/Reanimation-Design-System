Rail geometry primitive for the five mutation levels: M0 Dormant, M1 Ready, M2 Armed, M3 Live, M4 Critical.

`level` (0–4), `width`, `label`. M0 is a 2px `border-strong` path at 42% with an open interruption; M1 adds the activation node in `mutation-live`; M2 thickens to 4px with a strong junction; M3 energizes the route into segments with a localized glow (slow pulse only when motion is allowed); M4 switches to `status-danger` with a critical notch. Geometry escalates, not just color — the rail must read in grayscale.
